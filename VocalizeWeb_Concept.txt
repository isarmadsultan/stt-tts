WHAT IS VOCALIZEWEB?
--------------------
VocalizeWeb is a plug-and-play AI assistant that website owners can embed on 
their websites. It allows visitors to ask questions about the website's content 
using either text chat OR voice conversation - and get instant, accurate answers.

Think of it as giving every website its own "intelligent receptionist" that 
knows everything about the website and can talk to visitors 24/7.


THE PROBLEM WE SOLVE
--------------------
1. INFORMATION OVERLOAD
   Visitors struggle to find specific information on websites. They browse 
   through menus, scroll pages, and often leave frustrated.

2. OUTDATED CHATBOTS
   Traditional chatbots rely on manually curated knowledge bases. When website 
   content changes, chatbots give outdated or wrong information - damaging trust.

3. NO AUTO-SYNC
   There's no automatic way to keep an AI assistant updated with the latest 
   website content. Manual updates are expensive and error-prone.


OUR SOLUTION - THREE KEY INNOVATIONS
------------------------------------

[1] MULTI-MODAL INTERACTION
    - Text Chat: Traditional chatbot interface
    - Voice-to-Voice: Speak your question, hear the answer
    - Website owners choose: text only, voice only, or both

[2] INTELLIGENT CONTENT MANAGEMENT
    We classify website content into three types:
    
    • STRUCTURED: Products, faculty lists, pricing tables
      → Stored in database, queried precisely
      
    • UNSTRUCTURED: Blog posts, FAQs, policies
      → Stored as vector embeddings, searched semantically
      
    • SEMI-STRUCTURED: Mixed content with patterns
      → Hybrid storage and retrieval

[3] DOM-BASED AUTO-UPDATE (Our Secret Sauce!)
    - We take "snapshots" of the website's pages
    - Periodically compare current page to stored snapshot
    - Use vision AI to detect what changed
    - Automatically update ONLY the changed content
    - No manual re-training required!


HOW IT WORKS (SIMPLE FLOW)
--------------------------
1. Website owner signs up → gets an embed code
2. Paste code on website → AI widget appears
3. We scrape and classify website content
4. Visitors ask questions (text/voice) → get instant answers
5. Website content changes → we detect it → auto-update knowledge base

         [Visitor] ──→ [Ask Question] ──→ [AI Processes] ──→ [Answer]
              ↑                                                   │
              └─────────────────────────────────────────────────┘
                            (Text or Voice)


TECHNOLOGY STACK
----------------
• Speech-to-Text: OpenAI Whisper Turbo
• Language Model: GPT-4o mini (cost-efficient)
• Text-to-Speech: OpenAI TTS
• Vector Database: Weaviate/Redis
• Structured Data: PostgreSQL
• DOM Comparison: Vision Models (open-source)


WHO IS IT FOR?
--------------
• University websites (course info, faculty lookup)
• E-commerce sites (product queries, pricing)
• Corporate websites (services, contact info)
• Documentation portals (technical queries)
• Any content-heavy website


BUSINESS MODEL
--------------
SaaS (Software as a Service)
• Monthly/Annual subscription per website
• Tiered pricing based on:
  - Number of queries
  - Voice vs text-only
  - Update frequency
  - Analytics access
